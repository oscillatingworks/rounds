name: rounds
description: Ask a reviewer agent to review a change through rounds review threads, in a project where rounds is set up (a .review directory in the main checkout). Use after finishing a change worth a second look (code, a plan, a document), when the user asks for a review (an adversarial one too), or when a project rule says changes are reviewed before they are committed. Covers opening a thread, waiting for the verdict, answering findings round by round, and stopping for the human.
